# Alones

Конструктор и интерактивный лист персонажа мира Элонии. MVP 1.

Мобильное веб-приложение (PWA): работает офлайн, ставится на домашний экран, хранит данные локально в IndexedDB. Без регистрации.

## Что есть
- Создание персонажа в 7 шагов с автосохранением черновика: раса, подраса и дар Мелонианцев, подготовка (общий бюджет 10 очков), снаряжение, ордена, имя и портрет, проверка.
- Лист: здоровье и мораль с быстрым изменением, СП, характеристики, навыки и владения, инвентарь с уроном оружия, средства, ордена, врождённые свойства, категории техник.
- Полное редактирование без бюджета, с проверкой пределов и пересчётом максимумов.
- Разделы «Мир и лор» и «Рулбук» со структурой и поиском. Тексты подключаются через `src/data/articles.json`.

## Разработка
```bash
npm install
npm run dev      # локальный сервер
npm test         # движок правил и хранилище, включая проверочного персонажа Рина
npm run build    # сборка в dist/
```

## Устройство
- `src/data/` — справочники (расы, подрасы, навыки, оружие, ордена, правила, статьи). Игровые значения правятся здесь, без изменения кода.
- `src/domain/` — расчёты и правила (`rules.ts`), операции с персонажем (`character.ts`), типы.
- `src/storage/db.ts` — IndexedDB: атомарное создание, один активный черновик, версии схемы и миграции.
- `src/pages/`, `src/ui/` — интерфейс.
- `scripts/prepare_data.py` — импорт справочников из пакета MVP с применёнными решениями.
- `docs/DECISIONS.md` — журнал решений автора.

В персонаже хранятся вложения и правки, итоговые значения всегда вычисляются.

## Проверка отказа записи (A14)
В консоли браузера: `__alones.faults.failWrites = 1`, затем любое сохранение покажет ошибку с повтором.

## Публикация
Push в `main` запускает GitHub Actions: тесты, сборка и выкладка на GitHub Pages.
