# Решения по MVP 1

Источник: ТЗ «Конструктор персонажей Элонии», MVP 1 от 9 ноября 2026, и уточнения автора от того же дня.
Решения D01–D09 из ТЗ хранятся в `src/data/decisions.json`. Ниже — уточнения, принятые при разработке.

| № | Вопрос | Решение |
|---|---|---|
| 1 | Соулер и Дух | Урон Соулера = кубы + владение «Духовное». Дух отдельно не прибавляется (`damageAttribute: null`). |
| 2 | Клинковое оружие | Попадание — владением (Ловкость), сила удара — Силой. Урон = кубы + владение + Сила. Так задумано. |
| 3 | Привязка оружия | Огнемёт — «Технологическое». У «Древкового» пока нет оружия. Принято для прототипа. |
| 4 | critMargin, actionPoints | Только справочно, в расчётах не участвуют. |
| 5 | id категории техник | `souler_technique`, чтобы не совпадать с оружием `souler`. |
| 6 | Полное редактирование | Характеристика не ниже 1. Навык не ниже связанной характеристики. Предел 2 × характеристика. |
| 7 | Покупки в листе | Списывают средства так же, как при создании. |
| 8 | Мелонианцы | Врождённые свойства — заглушка до текстов автора. |
| 9 | Пример Рина | Здоровье 30/50 — демо-состояние после боя. При создании ресурсы полные. |
| 10 | Структура листа | Табы «Лист / Навыки / Вещи». |
| 11 | Урон на листе | Показывается у каждого оружия: «3к6 + 5 + 2». |
| 12 | Средства | Редактируются в листе, вкладка «Вещи». |
| 13 | Портреты | Только предзагруженные 21 портрет; загрузка своих — позже. |
| 14 | Меню «⋯» | Плейсхолдер для будущей информации об аккаунте. |
| 15 | Фильтры навыков | Все · шесть характеристик · Владение. |
| 16–18 | Контент лора и рулбука | Структура разделов есть, тексты пустые до передачи автором. |
| 20 | Названия | Alones — проект и игра. Элония — мир. |
